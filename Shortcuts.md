## New shortcut preferences for VS 2026 Insiders/Vscode

* Ctrl + P: Search files/members
  * Ctrl + 1 + M/F: Switch between file/member search
* Ctrl + Shift + P: Search features
* Shift + Alt + drag: Block select text to edit
* Shift + Alt + Up/Down: Add multiple cursors above/below
* Shift + Alt + Left/Right: Extend/shrink selection
* Shift + Alt + F: Format document
* Alt + Left/Right: Previous/next cursor location
* Ctrl + K -> Shift + Enter: Pin file
* Ctrl + K + C/U: Comment/uncomment
* Alt + Up/Down: Move line up/down
* Windows + V: Windows history paste
* Ctrl + Shift + R: Refactor (Extract Method)
* F2: Rename all references
